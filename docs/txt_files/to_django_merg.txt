# Step 1: 
### Add venv to project:
#### from project home
    python -m venv .venv
### Activate venv
#### for powershell
    .\.venv\Scripts\Activate.ps1

# Step 2: Install django
    pip install django a2wsgi
#### FastAPI recommends the separate a2wsgi package when using django
### then:
    pip freeze > requirments.txt

# Step 3: Create django project:
### move into web
    cd .\web\
### start django
    django-admin startproject dashboard
#### See Django Quickstart.md
